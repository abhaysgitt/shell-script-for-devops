# Shell Scripting for DevOps

Learning Shell Scripting from basics to real-world DevOps automation.

## Getting Started

```bash
git clone https://github.com/abhaysgitt/shell-script-for-devops.git
cd shell-script-for-devops
```

## Repository Structure

- `learn-scripts/` — Scripts from learning sessions
- `practice-scripts/` — 19 numbered scripts, from Bash basics to backup automation
- `devops-projects/` — AWS EC2, Docker deployment, and error handling

## What I'm Learning

- Variables, user input, and command-line arguments
- Conditionals, loops, and functions
- Linux file operations and user management
- Error handling and system monitoring
- Backup automation using `tar`, `gzip`, and cron
- AWS EC2 automation and Docker deployments

## Projects

- **Backup Automation:** `practice-scripts/19_backup.sh`
- **AWS EC2 Provisioning:** `devops-projects/create_ec2.sh`
- **Django App Deployment:** `devops-projects/deploy_django_app.sh`
